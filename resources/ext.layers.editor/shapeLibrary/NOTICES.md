# Symbol attribution and source notices

The symbol files retain their individual licenses. A standards number or
a Commons filename does not establish public-domain status. Source metadata
was checked on October 25, 2026 for all 1,385 files. The inventory records
1,015 public-domain claims, 359 CC0 claims, nine CC BY-SA 4.0 files, one
CC BY-SA 3.0 file and one GPL-2.0-or-later file.

All eleven attribution-bearing SVGs were matched to upstream SVG bytes after
the repository sanitizer; M002 uses its matching 2022 file and a historical
description revision. The other files have filename/metadata provenance,
rather than a full historical byte comparison. These are upstream license
claims, not a guarantee of copyright status in every jurisdiction.

Distribution changes: XML/editor metadata, comments and redundant whitespace
are removed; SVG data is also embedded in category JavaScript files.
The notices cover those embedded copies too. Existing artwork is unchanged
by this attribution update. Preserve these notices and applicable terms when
redistributing the assets. This does not change the software license or add
visible credits to wiki pages.
