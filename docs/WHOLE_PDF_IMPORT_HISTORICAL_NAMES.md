# Historical layer-set names in whole-PDF drafts

This advances Milestone 1 / HIST-4 / DATA-1 / OPS-1. Native page content may retain
a layer-set label admitted under earlier rules. Draft inspection must preserve
that exact saved label; it must not normalize it or silently rename the set.

The inert whole-PDF draft validator compares each target anchor's label to the
anchor in the exact captured saved scope. An unchanged label remains eligible
under the native historical-name rule. A different proposed label must pass the
current canonical-name checks. A label from another file/group grants no
exception, and a changed saved scope still refuses.

Stored member IDs, complete group membership, fixed source pins, native
temporary/admission pairs, source citations, history and saved markers retain
their existing checks. The exception supplies no read, editing or publication
authority: actual recovery and Save still perform fresh native checks. In
particular, retaining an old name for recovery does not promise that a changed
surface can be saved under that name; native publication decides that.

Production whole-PDF Import remains inactive. Client checks do not establish
complete native/browser, supported-version/mobile, upgrade or owner acceptance.
