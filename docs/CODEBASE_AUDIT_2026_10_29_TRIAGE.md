finding numbers have different meanings. The external audit and private evidence
stay local. The table records disposition, not a claim of release acceptance.

The renderer corrections preserve export choices and authorization while correcting rotated output and minimizing failure logs.
The complete standalone PHP suite passed 1,697 tests / 4,217 assertions with
one existing skip. Native privacy tests passed on both maintained supported
MediaWiki versions; the existing 1.44 PDF-export test passed with the corrected
renderer preloaded. The 1.45 test harness used a temporary test-access wrapper.
The approved legacy draft changes passed 207 affected tests and the full client
suite of 19,076 tests in 325 suites. An initial full run exposed one outdated
PDF test expecting dirty empty drafts to be skipped; the test was updated for
the approved behavior before the passing replay.

**Large rotated image correction:** A synthetic 10,000 × 10,000 rotated image failed under the maintained 1.45 wiki’s configured shell limits because its intermediate image reached approximately 14,148 × 14,148 pixels. The bounded correction renders large rotated layers into the visible viewport. The 1.45 renderer/privacy group passed 32 tests / 227 assertions, covering PNG, JPEG, transparency, narrow visible geometry and existing rotation/privacy cases. A corresponding unrotated RGB probe passed under the same limits. Exact-commit CI passed and the later candidate is installed on the 1.44 wiki; other configurations and output contexts are not claimed.

**Grayscale imported-image correction:** The owner approved the [visible correction](GRAYSCALE_LAYER_COLOR_BEHAVIOUR_BRIEF.md). Three synthetic grayscale cases failed before the fix and passed afterward. Color-background, opacity, large-rotation, PDF conversion and privacy checks also passed in the 1.45 native group. Exact-commit CI and installed-candidate verification passed, and the owner confirmed the synthetic comparison. Broader release acceptance remains pending.
