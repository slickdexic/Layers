# Edit and view layer sets on their owning page

Hover over an image, slide or PDF page, focus it with the keyboard, or tap it to
show its layer actions. **View full size** opens the viewer. **Edit layers** is
available when the current owning page and layer set permit editing. A `noedit`
embed or historical view does not offer Edit.

Use the owning page's editor to Import from another page, rename, Save or Close.
An admitted missing image or slide layer set opens empty under its requested
name; the first explicit Save creates it in that page's history. Import and
Restore remain local until Save. Other pages' layer sets remain independent.

The former **Layer sets on this page** links box is removed. Overlay labels,
viewer controls, exact source versions, parser caching, authorization and editor
routes are preserved. Legacy special pages and API definitions remain registered;
removing this box does not authorize editing another page's layer set.
