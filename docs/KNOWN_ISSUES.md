# Known issues and verified limits

**Updated October 4, 2026.** This register reconciles the project charter's Partial and Open criteria with the current implementation and the dated evidence in [current status](CURRENT_STATUS.md). It describes the local project state, not a released version or a claim that the owner's wiki has been upgraded. Where a result is unverified, that is stated explicitly. The earlier R6 review remains useful for its original evidence; the status table below supersedes its old “open” labels.

Layers is a MediaWiki extension. Docker is used only to run the existing test environment.

## Operational guidance

For a normal bug report, include the branch/commit, MediaWiki/PHP/browser versions, media type (image, PDF or slide), minimal markup, expected and actual behavior, and sanitized console/API errors. Do not include confidential layer content, tokens or database dumps in public issues. Report security issues privately as described in [SECURITY.md](../SECURITY.md).

## Not verified in this refresh

This is a source-and-documentation audit, not a production-wiki acceptance run.
